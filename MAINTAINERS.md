## Becoming a co-maintainer

1. 3 merged PRs in this repository (tests or docs count).
2. One release-related task: changelog, pack check, or issue triage.
3. Read `GOVERNANCE.md` and `CONTRIBUTING.md`.
4. Open an issue titled `co-maintainer: <package>`; current maintainer reviews within 14 days.

Co-maintainers get review and release rights for the named package only. They are listed here and in `package.json` `author`/`contributors` when appropriate.
